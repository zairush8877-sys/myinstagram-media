# CLAUDE.md — правила работы в этом репозитории

## Автоматические самопроверки / мониторинг — ТОЛЬКО по явной просьбе
- **Не включать самостоятельно** периодические самопроверки, «вахту» над PR, ежедневные/часовые
  триггеры (`send_later`/`create_trigger`) или подписку на события PR.
- Заводить их **только если Заира явно попросила** (например: «следи за PR», «проверяй раз в день»).
- Если явного запроса не было — **не создавать таймеры и не подписываться** на события; при
  необходимости просто спросить, нужен ли мониторинг.
- Когда просьба есть — соблюдать заданный ритм (по умолчанию, если не указано иное, уточнить интервал).
- По просьбе «отключить проверку» — удалить активный триггер (`delete_trigger`) и отписаться
  (`unsubscribe_pr_activity`), не оставляя фоновых задач.

## Контент
- Медиатека и статусы — в `content/media/README.md`. Форматы: сторис (1080×1920), карусель (1080×1350),
  рилс. Тексты/сценарии — в манифестах тем.
- Медицинские факты для контента — сверять по источникам, добавлять дисклеймеры; не публиковать
  непроверённую статистику.
- PHI (данные пациентов: ФИО, даты рождения, телефоны) в репозиторий не класть; для контента —
  полностью анонимизировать.
